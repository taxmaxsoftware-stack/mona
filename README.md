## Ground rules

- Use current IRS sources first. Do not invent tax rules.
- Flag every threshold, credit, deduction, penalty or law that changes by tax year with **⚠ YEAR CHANGE**.
- Don't write quiz questions that only test memorized form line numbers.
- Every set of closing remarks or key takeaways ends by asking for questions, pointing students to **portal → Lessons** (scroll down and describe the topic they need help with), and encouraging practice in the **demo environment**.

> **Disclaimer:** These materials are for training. They are not legal or tax advice. Amounts and rules change. Check the current IRS instructions before preparing any return.
