# Tax-Training Content Standards

These standards apply to every lesson in this repository. Reviewers should reject
any lesson that does not meet them.

## 1. Sourcing rules

1. **Use current IRS sources first.** In priority order:
   1. Internal Revenue Code (IRC) and Treasury Regulations
   2. Current-year IRS form instructions and publications
   3. Revenue procedures, notices and other IRS guidance (e.g., the annual inflation-adjustment Rev. Proc.)
   4. IRS.gov pages (EITC Central, Tax Pro pages, newsroom)
   5. Secondary sources: only to find a primary source, never cited as authority
2. **Do not invent tax rules.** Every rule, threshold, and dollar amount must trace to a
   reference in the lesson's *IRS References* section.
3. **If a figure cannot be confirmed in an IRS source, leave it out.** Point the reader
   to the source to check instead.
4. Record a **"Sources verified as of"** date at the top of every lesson.

## 2. Year-sensitivity rules

Tax law changes. Every lesson must make the tax year obvious.

- Every dollar threshold, credit amount, deduction amount or penalty gets a
  **tax year** (or, for preparer penalties, the **calendar year the return is filed**).
- Mark changes with the **⚠ YEAR CHANGE** flag, and say what changed, when, and
  which law or guidance made the change (e.g., *P.L. 119-21, the One, Big, Beautiful Bill Act*).
- Each lesson includes a **Year-Sensitive Figures** table.
- Inflation-indexed amounts are labelled "indexed annually".

## 3. Required lesson structure

Every lesson contains these ten sections, in this order:

1. Learning objectives
2. Plain-language explanation
3. Applicable IRS forms
4. Due-diligence requirements
5. Examples
6. Common preparer mistakes
7. Practice scenario
8. Quiz
9. Answer explanations
10. IRS references

Optional sections that may follow: *Key Takeaways & Closing Remarks* (see §5).

Use [`templates/lesson-template.md`](templates/lesson-template.md) as the starting point.

## 4. Assessment rules

- **Do not write questions that only test memorized form line numbers.** Questions
  test judgment: eligibility, what to ask, what to document, which form applies and
  why, and what the consequence is.
- Prefer scenario-based multiple choice, "what should the preparer do next" items,
  and short-answer items that call for a documented inquiry.
- Every answer explanation states **why** the correct answer is right **and** why
  each distractor is wrong, citing the governing rule.

## 5. Closing remarks / key takeaways

Whenever a lesson or session includes **closing remarks** or **key takeaways**,
always end with these three items:

1. **Questions:** "Does anyone have any questions?"
2. **Portal help:** "If you need more help, open the **portal → Lessons**, scroll
   down, and describe the lesson or topic you need help with."
3. **Practice:** "Use the **demo environment** to practice what we covered today."

## 6. Tone and accessibility

- Write in plain language. Define each acronym the first time you use it in a lesson.
- Use "taxpayer" or "client" with they/them pronouns in examples.
- Use fictional names and fictional TINs only (e.g., `XXX-XX-1234`). Never use real taxpayer data.
